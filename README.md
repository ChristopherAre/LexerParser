# 🚀 Compilador LexerParser

Repositorio correspondiente al desarrollo de las fases de un compilador (Análisis Léxico, Sintáctico y Semántico), diseñado bajo los requerimientos de la plantilla institucional con soporte de nomenclatura bilingüe y reporte formal de la Tabla de Símbolos.

---

## 📂 Estructura del Proyecto

```text
LexerParser/
├── lexer/         # Módulo de análisis léxico y generación de tokens
├── parser/        # Módulo sintáctico y construcción del AST
├── semantic/      # Analizador semántico, control de tipos y alcance
├── tests/         # Casos de prueba y archivos de código fuente
└── main.py        # Interfaz principal de integración y ejecución
